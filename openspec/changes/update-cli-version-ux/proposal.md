# Change: 提升版本查询与更新流程的交互体验

## Why
当前版本查询与更新过程缺少加载与更新中的反馈，且更新时仅支持手动输入版本号。通过更清晰的过程提示与键盘可选交互，降低等待与误操作成本，提升用户体验与可控性。

## What Changes
- 在获取线上版本时展示加载提示，并在结果输出后结束提示
- 更新流程中展示更新进行中的状态，并在完成/失败后提示结果
- 在 `--update` 场景支持键盘选择版本并回车确认，非交互环境自动回退为文本输入
- 统一关键提示语与错误提示，减少不确定性

## Impact
- Affected specs: `cli-version-update`
- Affected code: `bin/cli.js`, `lib/*`（版本获取、更新流程、CLI 交互输出）
